# EDGE 101 接线图 (依据 DFRobot wiki DFR1283 实测规格)

> 引脚以 `include/config.h` 为准, 本表与固件一致。
> **板级事实**: ESP32 原版 (非 S3) · 16MB Flash · 板载 RJ45 以太网 ·
> 11 路原生 GPIO, 其中 4 路 (P34/P37/P38/P39) 只能输入 →
> **可用输出 6 路: GPIO5 / 12 / 14 / 15 / 18 / 23**。

## 引脚总表

| 信号 | 引脚 | 说明 |
|---|---|---|
| HL2 UART TX | GPIO5 | 板→HL2 RX (Serial2 重映射, 38400) |
| HL2 UART RX | GPIO12 | 板←HL2 TX (内部下拉, 仅作 RX 无影响) |
| 步进 STEP | GPIO14 | 步脉冲 (固件非阻塞输出) |
| 步进 DIR | GPIO15 | 方向; **复用板载 LED** (DIR=LOW 时 LED 亮, 可当方向指示) |
| I2C SDA | GPIO18 | 板载默认 I2C, 接 PCA9685 |
| I2C SCL | GPIO23 | 板载默认 I2C, 接 PCA9685 |

不可用 (已占用/只读): P33/P34 (4G 模组 PCIe UART), P37/P38/P39 (只读输入;
P38=板载按钮), 34/37/38/39 无上拉。

## 外设接线

### HuskyLens 2 (基础版, Gravity I2C/UART 口 → 用 UART)

| 线 | 接 | 说明 |
|---|---|---|
| 5V | 板 5V | HL2 峰值 ~1.5W, 板载 5V (USB 5V/2A 输入) 可带 |
| GND | GND | 共地 |
| TX | GPIO12 | 交叉: HL2 TX → 板 RX |
| RX | GPIO5 | 板 TX → HL2 RX |

- 波特率 **38400** (HL2 默认)。
- HL2 的 TX 是 5V 电平进 3.3V IO: 在 HL2 TX → 板 GPIO12 之间加
  1kΩ+2kΩ 分压, 或 3.3V 电平位移 (板侧有内部下拉, 低电平安全)。

### 步进电机 (传送带: 42 两相 + MKS SERVO42C 闭环 PCBA)

驱动器 = **Makerbase MKS SERVO42C** (闭环 PCBA, 贴电机尾部):
板载 **16384 线磁编码器** + FOC 矢量三环, 开环/矢量闭环/串口控制三模式,
堵转保护, 单圈内上电自动回零。安装/接线/参数参考:
https://blog.csdn.net/gjy_skyblue/article/details/120565771

| 线 | 驱动器 | 接 |
|---|---|---|
| PUL+ | STEP | GPIO14 |
| DIR+ | DIR | GPIO5 |
| EN+  | EN  | **不接线** (2026-11-03 实测 SERVO42C 低电平使能: 浮空=使能, 高电平=禁能; 想固化可跳 GND) |
| GND  | GND | 共地 |
| 电机动力 | 12V | 12V/1.5A+ 独立供电 (不并 5V 轨; 实际电压按电机铭牌) |

- **EN 由外部决定, 固件不碰**: 当前不接线 (浮空=使能, 实测可用)。MCP23017
  装上后 PA0 可接管 (McpEn, `kActiveLow=true`): running=使能 (EN 低)、
  stopped/paused/fault=禁能 (EN 高, 停带断线圈电)。详见下文 MCP23017 节。

- **工作模式: 矢量闭环 (STEP/DIR)** — 编码器兜底, 堵转/丢步由驱动器处理
  (可启用堵转保护, LED 状态指示)。开环模式亦可; **串口控制模式暂不用**
  (需要第三路 UART, EDGE 101 无空闲)。
- **安装注意** (文档第 2 部分): 磁环 (6×2.5) 必须粘在电机轴**中间**且水平;
  4 线顺序 A+ A- B+ B-, 插错上电屏幕提示 "Phase Line Error!", 断电重调。
- **细分**: 在驱动器上设 (屏幕/串口, 1~256 任意)。**2026-11-03 实测定稿:
  `STEPS_PER_MM=68.7`** (3200 步 = 46.6mm 卷尺+基准)。细分数/导程未确认,
  确认后按公式重算并复核。
- 1.0 m/s ≈ 68700 脉冲/秒 (按 68.7 步/mm)。
- 位置对账: 驱动器内可开"单圈内上电自动回零"; 要不要料道末端加光电开关
  做长期对账, 见 OPEN_QUESTIONS 第 3 项。
- **电机侧 6 线全部终结在驱动器, 不碰板子**: 线圈 4 线 A+ A- B+ B- →
  驱动器 A+/A-/B+/B- 端子; 动力 2 线 12V (V+/GND) → 驱动器动力端子。
  板子只出控制侧 STEP/DIR/GND 三根。

### 3 路舵机 (LEDC PWM 直连, 12/15/33)

2026-10-30 起弃 PCA9685, 信号线直连 GPIO (7 路输出 GPIO 5/12/14/15/18/23/33
全部用满; I2C 18/23 留给 HL2 预留):

| 舵机 | 信号 | GPIO | 备注 |
|---|---|---|---|
| 1 号 | PWM | GPIO12 | 该脚内部下拉, 上电固件接管前可能抖一次归零 |
| 2 号 | PWM | GPIO15 | 与板载 LED 复用, LED 从此常灭 (低电平点亮, PWM 平均为高) |
| 3 号 | PWM | GPIO33 | 原 U1TXD/4G 复用, 4G 不用, 无影响 |

- 50Hz / 15bit: 0°=1000µs, 90°=1450µs。信号 3.3V, 舵机独立 5V 供电。
- 上电即归位 0° (推杆收回)。

### MCP23017 I2C 数字 IO 扩展 (光门 ×3, DFR0626)

与 HL2 **预留同一条 I2C 总线** (P18 SDA / P23 SCL), 地址 0x27。参考:
https://wiki.dfrobot.com.cn/_SKU_DFR0626_MCP23017_IIC_to_16_digital_IO_expansion_module

| 线 | 接 | 说明 |
|---|---|---|
| VCC | 5V | 接口供电 3.3~5.5V, 输出电平跟随 VCC |
| GND | GND | 共地 |
| C (SCL) | GPIO23 | 与 HL2 (预留) 共线 |
| D (SDA) | GPIO18 | 与 HL2 (预留) 共线 |
| A0/A1/A2 | 拨码全 1 | I2C 地址 0x27 (默认值) |
| PA0 | 驱动器 EN+ | 低电平使能 (SERVO42C 2026-11-03 实测: 使能=EN 低; `McpEn.h kActiveLow=true`) — 现阶段 EN 不接线, 预留 |
| PB0/PB1/PB2 | 光门 1/2/3 | 见下节 (推杆推出时序触发, 输入 + 内部上拉) |

- **固件自动检测**: 启动日志 `[mcp] MCP23017 @0x27 在线` 或
  `[mcp] MCP23017 未检测到 (光门未装; 步进 EN 未接线: 浮空=使能, 高=禁能, 2026-11-03 实测)`。
- 在线后 EN 随传送带状态: `running`=使能 (EN 低), `stopped/paused/fault`=禁能
  (EN 高, 停带断线圈电)。串口 `stepper <n>` 手动脉冲走 RMT 通道, 不涉及 EN。
- **剩余 13 路预留** (PA1~PA7, PB3~PB7): 料道末端对账光电/限位/急停等数字量,
  输入模式 + 内部上拉即可 (OPEN_QUESTIONS 3②)。

### 光门 ×3 (推杆推出时序触发, 推杆【前侧/上游】)

3 个**透过式光电开关** (对射式, NPN 开集输出, 5V, 如 E3T-ST61 或同级;
采购注意: 必须是 NPN 开集 + 支持 5V 供电, PNP 源型的不配内部上拉用不了):

**安装布局示意图: `gate_layout.svg`** (本目录, 俯视 + 侧视高度; 也内嵌在
loop_ui「Laya 工业决策回路」页「📐 分拣线光门安装布局」折叠区)。

| 光门 | 安装位置 | MCP23017 | 触发对象 |
|---|---|---|---|
| 1 号 | 1 号推杆**前方 (上游)** | PB0 | 1 号分拣器 |
| 2 号 | 2 号推杆**前方 (上游)** | PB1 | 2 号分拣器 |
| 3 号 | 3 号推杆**前方 (上游)** | PB2 | 3 号分拣器 |

```
光门安装距离 = 推杆推料点 − 带速 × (推出动作时间 + 余量)
1 m/s, 推出 400ms + 余量 100ms → 推杆推料点前方 0.5 m
```

(为什么装前侧: 推出动作必须在物品到达推杆推料点**之前**完成, 光门落沿
是"推出开始"时刻。公式与标定全文见 `docs/sort-mqtt.md` 「光门时序」。)

| 线 | 接 | 说明 |
|---|---|---|
| V+ | 5V | 光电工作电源 |
| COM/GND | GND | 共地 |
| OUT (NPN 开集) | PB0/PB1/PB2 | 无物品=HIGH (内部上拉), 物品挡光=LOW (开集拉低) |

- 固件配置: `IODIR_B` 输入 + `GPPU_B` 内部上拉 (启动自动, 每 loop 轮询,
  10ms 去抖, 落沿 = 物品到达)。光门未接 / MCP23017 未接时, 网关
  `divert_trigger=photo` 的 divert 先走**虚拟光门** (按带面位置预测,
  见下节), 再回退 immediate (串口日志说明原因)。
- 件距约束: 相邻件 ≥ 带速 × 0.9s (1m/s → ≥0.9m), 否则漏拨
  (见 `docs/sort-mqtt.md` 光门时序节)。
- 调试: 串口 `gates` → `gates: ok=1 s1=1 s2=1 s3=1` (通光);
  用手/件挡光对应路变 `0`。三路全 1 且 ok=1 表示接线与供电正常。

### 虚拟光门标定 (光门未接线前: 让 photo 时序照样成立)

未装物理光门时, 固件用「HL2 检测锚点 + 带速匀速外推」预测物品过光门线
时刻 (`Track.h`), 到点推出 — 时序与 `gate_layout.svg` 一致。需要标定
`config.h` 三个量 (沿带面量, 卷尺量即可):

| 标定项 | 含义 | 测量方法 |
|---|---|---|
| `GATE_DIST_MM[3]` | 相机参考平面 → 1/2/3 号光门安装位 | 相机正下方带面点作 0 点, 沿带面量到各推杆前方光门位 (= 安装公式: 推料点 − 带速×(400ms+余量)) |
| `VIEW_WIDTH_MM` | 相机视野在带面平面的宽度 | 带面贴两个相距已知的标记, 量出它们各自占画面宽的比例 → FOV = 标记间距 ÷ 比例差 |
| `ITEM_PITCH_MM` | photo job 件距 (第 k 件在首件后 k 件距/v) | 按上游排产的实际件距 (≥ 带速×0.9s) |

验证 (不依赖光门硬件):
```
串口: vision red_apple          # 注入检测锚点 (p0=0, 视为在相机中心)
网关: divert trigger=photo      # -> 串口 [vgate] 预测 ~500ms 后过光门线
串口: track                     # 查看锚点/带速/标定值
```
运动事件时间线 (网关 `GET /motion` 或 `sort/event/motion`):
`armed(via=virtual 前) -> busy(via=virtual) -> ready(via=done)`。
光门硬件到位后**自动优先物理光门**, 虚拟光门仅在 `gateOk=false` 时启用。

### 推杆 (3 个舵机) 接线要点

- 3 个舵机信号线**直连 GPIO12/15/33** (LEDC 50Hz PWM, 1/2/3 号 = 1/2/3 号
  料道, 各驱动 1 条**推杆**)。2026-10-30 起弃 PCA9685。
- 扫掠: 0°(推杆收回) ↔ 90°(推杆推出), 一件 = 一次推出, qty=N 连推 N 次。
  舵机型号/推杆行程几何待现场确认 (OPEN_QUESTIONS 第 4 条)。
- 舵机独立 5V 供电 (≥2A), 信号 3.3V, GND 共地。

### 以太网 (板载 RJ45, 网线直连)

- 无需外接模块。PHY=**IP101** (板内 MDIO 走线: MDC=GPIO4/MDIO=GPIO13/
  PWR=GPIO2/参考时钟=GPIO0, 参数出自 DFRobot 官方 SDK, 不占扩展口)。
- 固件 `ETH.begin(ETH_PHY_TLK110, 1, 4, 13, 2, ETH_CLOCK_GPIO0_IN)` 后
  停 DHCP 设静态 192.168.2.2/24 (config.h 可改)。
- 网线: EDGE101 ↔ 本机 (192.168.2.1/24, broker :1883)。
- **注意**: 本机直连若不开 DHCP/共享, 静态 IP 方案直接可用 (我们就是静态);
  wiki 演示的「电脑共享网络」场景可跳过。

## 供电架构

```
USB 5V/2A (或 DC 9-26V 端子)
  └── EDGE101 板载 (主控 + 4G 模组 + HL2)   ~1W 静态 + HL2 峰值
12V/1.5A+ 独立电源 ── 步进驱动器 VMOT
5V/2A+ 独立电源  ─── 舵机 (LEDC 直连 12/15/33)   [与 12V 共用 GND 共地]
```

- 三处 GND 必须共地 (星形接地更好)。
- 若只有一个电源: DC 端子 9-26V + 板载 5V 带 HL2 + 外接 LDO/Buck 出 12V/5V 两路。

## 上电顺序与调试

1. 先不接电机/舵机, 只接 HL2: 串口 (115200, Type-C) 看
   `[hl2] ...` / `[eth] ...` / `[mqtt] connected`。
2. 接一个舵机到 GPIO12, 串口发 `sweep 1` 验证扫掠方向与角度。
3. 接步进, 串口发 `stepper 1000` (≈14.6mm @68.7步/mm, 2026-11-03 实测定稿,
   见 OPEN #6⑧ 带速标定) 验证转向 (DIR=LOW = 正向, 物品向分拣器; 皮带反了就把 DIR+ 接线反相)。
4. 接光门 ×3 (各推杆前侧), 串口 `gates` 确认三路上拉 HIGH、挡光变 LOW;
   未接光门时可用 `vision <material>` + `track` 验证虚拟光门时序。
5. 全接上, 网关 `POST /dispatch` 走一次完整闭环。

## 调试命令 (串口控制台)

```
help | state | eth | mqtt | stepstat | stepinit | gates | track | reboot
     | stepper <n> | sweep <n> | vision <material>
```

- `track`: 虚拟光门状态 — 当前带速 / 检测锚点 (物料 + p0 + 时效) /
  标定值 (光门距离 ×3, 件距, 视野宽度)。
